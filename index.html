About this space

Designed as a lightweight gateway for experiments, utilities, and prototypes that sit adjacent to the main Thinking Systems website.

Hosted at playground.thinkingsystems.co.uk.

What this is

A companion space for digital tools and rapid ideas.

The main Thinking Systems site focuses on services, case studies, and contact. This playground is a more hands-on companion: a place for prototypes, internal tools, and public-facing experiments that are still useful on their own.

Applications

Current playground tools

Each application runs directly in the browser, with a small server-side proxy used where secrets need to stay off the client.

Word Counter

Word count, readability, keyword density, and reading-time analysis in one tool.

Readability Calculator

A focused Gunning Fog calculator for checking how difficult a text is to read.

Weather Lookup

Current conditions with a simple clothing recommendation powered via a server-side proxy.

Zuzu Booker

Booking and holiday-aware cost calculator for date-based planning.

Prompt Examples

A browsable prompt library for experiments, reference, and inspiration.

Draw The Line

An interactive experiment exploring categories, events, and threshold-based inputs.

Recycle

A standalone playground project within the broader collection of tests and ideas.

Jokes

A lightweight joke generator built as a small creative browser experiment.
