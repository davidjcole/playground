Using the app

How to create a tracked URL

The main builder page helps you create a full tracking URL from a small set of inputs. Start on the Build URLs page and fill out the fields from top to bottom.

Region identifies the geographic audience or team using the link. Landing page URL is the destination page you want users to visit.

UTM source describes the platform or channel, such as Facebook, ActionKit, WhatsApp, or Google. UTM medium describes the type of traffic, such as email, owned-social, paid-social, or referral.

Date is used by the automatic naming logic for campaign and source values. Topic gives the campaign a short, readable subject, for example `climate-finance`, `petition`, or `training`.

The app automatically generates UTM campaign and Source (ActionKit) from the selected inputs. You can keep those generated values or edit them manually if your team needs a specific naming pattern.

Once the fields are complete, the Final linking URL preview updates automatically. Use Copy URL to copy it, or Save URL to store it in the local history database.

The History page shows previously saved URLs. The Settings page controls which regions, UTM sources, and UTM media appear in the dropdowns.
